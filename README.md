# Test-AI-Chatbot

This was a test artifact (a minimal Flask scaffold with a static page) used while developing the active project. The real implementation lives at [github.com/dparikh79/AI-Chatbot](https://github.com/dparikh79/AI-Chatbot): a multi-tenant Flask app that turns PDFs into a branded, embeddable chat widget using TF-IDF retrieval and GPT-3.5, with per-tenant JS served from S3/CloudFront. This repo is archived and kept only for reference.
